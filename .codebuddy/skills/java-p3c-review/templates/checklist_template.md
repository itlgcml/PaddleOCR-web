## 阶段 1：命名风格、常量定义、代码格式

### 命名风格 (NM)
- [ ] **NM-01** 命名无下划线/美元符号开头或结尾 【强制】
- [ ] **NM-02** 无拼音与英文混合命名 【强制】
- [ ] **NM-03** 类名使用 UpperCamelCase 【强制】
- [ ] **NM-04** 方法/变量使用 lowerCamelCase 【强制】
- [ ] **NM-05** 常量全大写下划线分隔 【强制】
- [ ] **NM-06** 抽象类以 Abstract/Base 开头，异常类以 Exception 结尾 【强制】
- [ ] **NM-07** 数组定义类型与中括号紧挨相连 【强制】
- [ ] **NM-08** POJO 布尔属性不加 is 前缀 【强制】
- [ ] **NM-09** 包名全小写单数形式 【强制】
- [ ] **NM-10** 杜绝不规范缩写 【强制】
- [ ] **NM-11** 使用完整单词表达语义 【推荐】
- [ ] **NM-12** 设计模式命名体现具体模式 【推荐】
- [ ] **NM-13** 接口方法和属性不加修饰符 【推荐】

### 常量定义 (CST)
- [ ] **CST-01** 无魔法值直接出现在代码中（除 -1, 0, 1, 2） 【强制】
- [ ] **CST-02** long/L 使用大写 L 【强制】
- [ ] **CST-03** 常量按功能归类 【推荐】

### 代码格式 (FMT)
- [ ] **FMT-01** 大括号使用约定（左不换行、右换行） 【强制】
- [ ] **FMT-02** 小括号前后空格正确 【强制】
- [ ] **FMT-03** 4 空格缩进 【强制】
- [ ] **FMT-04** 运算符前后加空格 【强制】
- [ ] **FMT-05** 单行不超过 120 字符 【强制】
- [ ] **FMT-06** UTF-8 编码、Unix 换行 【强制】

## 阶段 2：OOP 规范、集合处理

### OOP 规范 (OOP)
- [ ] **OOP-01** 静态变量用类名访问 【强制】
- [ ] **OOP-02** 覆写方法加 @Override 【强制】
- [ ] **OOP-03** equals 用常量调用避免 NPE 【强制】
- [ ] **OOP-04** 包装类用 equals 比较（不能用 ==） 【强制】🔴
- [ ] **OOP-05** POJO 属性用包装类型 【强制】
- [ ] **OOP-06** POJO 不写属性默认值 【强制】
- [ ] **OOP-07** POJO 必须写 toString 【强制】

### 集合处理 (COL)
- [ ] **COL-01** 重写 equals 必重写 hashCode 【强制】
- [ ] **COL-02** subList 不强转 ArrayList 【强制】
- [ ] **COL-03** 集合转数组用 toArray(T[]) 【强制】
- [ ] **COL-04** Arrays.asList 不修改（增删元素） 【强制】
- [ ] **COL-05** foreach 不 remove/add 【强制】🔴
- [ ] **COL-06** Comparator 满足三条件（自反/对称/传递） 【强制】

## 阶段 3：并发处理、控制语句、注释规约

### 并发处理 (CON) 🔴 Critical 重点关注
- [ ] **CON-01** 线程池必须通过 ThreadPoolExecutor 创建 【强制】🔴
- [ ] **CON-02** 线程必须指定有意义的名称 【强制】
- [ ] **CON-03** SimpleDateFormat 不允许使用 static 【强制】🔴
- [ ] **CON-04** 锁粒度必须最小化 【强制】
- [ ] **CON-05** 多资源加锁顺序必须一致（避免死锁） 【强制】

### 控制语句 (CTL)
- [ ] **CTL-01** switch 必须包含 default 【强制】
- [ ] **CTL-02** if/else/for/while/do 必须加大括号 【强制】
- [ ] **CTL-03** 并发场景等值判断用常量调用 equals 【强制】

### 注释规约 (CMT)
- [ ] **CMT-01** 类必须有 Javadoc 注释 【强制】
- [ ] **CMT-02** 抽象方法必须有 Javadoc 注释 【强制】
- [ ] **CMT-03** 方法注释不写创建者/日期 【强制】

## 阶段 4：工程结构

### 工程结构 (ENG)
- [ ] **ENG-01** Controller 层禁止直接操作数据库 【强制】🔴
- [ ] **ENG-02** 领域模型命名符合规范（DO/DTO/VO） 【推荐】
- [ ] **ENG-03** Query 超过 2 参数不用 Map 【推荐】

## 阶段 5：异常处理、日志规约、安全规约

### 异常处理 (EX)
- [ ] **EX-01** 不允许 catch RuntimeException 规避预检查异常 【强制】
- [ ] **EX-02** 异常不允许做流程控制 【强制】
- [ ] **EX-03** catch 必须区分异常类型处理 【强制】
- [ ] **EX-04** finally 必须关闭资源 【强制】
- [ ] **EX-05** finally 不允许有 return 语句（严重） 【强制】🔴

### 日志规约 (LOG)
- [ ] **LOG-01** 统一使用 SLF4J 而非 Log4j/Logback 【强制】
- [ ] **LOG-02** 日志文件保存 >= 15 天 【强制】
- [ ] **LOG-03** 用占位符 `{}` 而非字符串拼接 【强制】
- [ ] **LOG-04** 异常信息必须包含堆栈 【强制】

### 安全规约 (SEC) 🔴 Critical 重点关注
- [ ] **SEC-01** 用户页面必须有权限校验 【强制】🔴
- [ ] **SEC-02** 敏感数据必须脱敏展示 【强制】🔴
- [ ] **SEC-03** SQL 必须用参数绑定防注入 【强制】🔴
- [ ] **SEC-04** 用户输入参数必须有效性校验 【强制】🔴
- [ ] **SEC-05** 禁止向 HTML 输出未经转义的用户数据（XSS） 【强制】🔴
- [ ] **SEC-06** 表单/AJAX 提交必须有 CSRF 防护 【强制】🔴
- [ ] **SEC-07** 短信/邮件/支付等必须实现防重放 【强制】🔴

## 阶段 6：MySQL 规约

### 建表规约 (TBL)
- [ ] **TBL-01** 布尔字段 is_xxx 命名 【强制】
- [ ] **TBL-02** 表名/字段名小写 【强制】
- [ ] **TBL-03** 表名单数 【强制】
- [ ] **TBL-04** 禁用保留字 【强制】
- [ ] **TBL-05** 索引命名规范（pk_/uk_/idx_） 【强制】
- [ ] **TBL-06** 小数用 decimal 而非 float/double 【强制】

### SQL 语句 (SQL)
- [ ] **SQL-01** 用 count(*) 而非 count(列名) 【强制】
- [ ] **SQL-02** count distinct 去重统计 【强制】
- [ ] **SQL-15** 用 `#{}` 而非 `${}`（防注入） 【强制】🔴

### ORM 映射 (ORM)
- [ ] **ORM-01** 禁用 `*` 查询 【强制】
- [ ] **ORM-02** 布尔属性 is_xxx 【强制】
- [ ] **ORM-04** 参数用 `#{}` 绑定 【强制】🔴
